# Third-Party Notices

CYRE uses or may use third-party open-source software components. This file documents their licenses and any required attribution.

## Current Dependencies (Sprint 2)

As of Sprint 2, **no third-party runtime dependencies** are included in the CYRE codebase.  
Development tools (Homebrew, Git, GitHub CLI, Node.js, pnpm, Conda, VS Code) are used during development but are not distributed as part of CYRE.

## Future Dependencies

When third-party libraries are added to the CYRE codebase, the following information will be recorded here:

- **Library name**
- **Version**
- **License type** (MIT, Apache-2.0, BSD, etc.)
- **Purpose**
- **Attribution requirements** (if any)

This file will be updated accordingly.

## Reporting Missing Notices

If you believe a third-party license is missing or incorrectly documented, please contact the owner privately.

## License Compliance

CYRE will comply with all open-source license obligations. If a dependency's license requires source code disclosure, that dependency will be isolated so as not to affect the proprietary status of the core engine.
