# CYRE v1.0 Verification

This document records the verified repository state after Sprint 8.

## Verification Command

```bash
pnpm verify
```

This expands to:

```bash
pnpm audit:engine
pnpm audit:placeholders
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Known Limitations

- Studio production bundle is approximately 1.14 MB and triggers Vite's chunk-size warning.
- The editor still contains legacy UI panels not yet fully driven by the canonical cyber runtime.
- Sprint 9 Studio integration is verified at the application state level, not yet through browser automation.

## Unsupported Platforms

- Automated browser UI tests are not configured.
