# Contributing to CYRE

## Current Status

CYRE is currently a **private, proprietary** project. Public contributions are **not accepted** at this time.

## Future Contribution Policy

When the project opens to external contributors, the following policy will apply:

1. **Contributor License Agreement (CLA)** — All contributors must sign a CLA before any contribution is merged.
2. **Coding Standards** — Contributions must follow the project's TypeScript, React, and documentation conventions.
3. **Testing** — New code must include appropriate unit/integration tests and pass existing CI checks.
4. **Documentation** — Public APIs, modules, and scenarios must be documented.
5. **Review** — All contributions will be reviewed by the owner.

## Reporting Issues

For non-security issues, once the project is open, issues can be reported via GitHub Issues.  
For security vulnerabilities, see [SECURITY.md](SECURITY.md) (to be added later).

## Questions

For questions about contributing, contact the owner.
