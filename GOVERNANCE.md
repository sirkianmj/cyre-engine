# CYRE Project Governance

## Maintainer & Owner

The sole maintainer and owner of CYRE is **ForgeX4 / Kian M.J.** All rights and responsibilities rest with the owner.

## Decision-Making

- All architectural, product, release, and strategic decisions are made by the owner.
- If external contributors are accepted in the future, they will be required to sign a Contributor License Agreement (CLA) or equivalent before any contribution is merged.
- Contributions must follow the project's coding standards and pass all automated tests.

## Code of Conduct

All participants (including the owner and any future collaborators) are expected to behave professionally and respectfully. Harassment, discrimination, or unprofessional conduct will not be tolerated.

## Versioning & Releases

- CYRE uses [Semantic Versioning](https://semver.org/) (MAJOR.MINOR.PATCH).
- Releases are tagged in the Git repository with the format `vX.Y.Z`.
- Release notes will be published in the repository documentation.

## Security Policy

- Security vulnerabilities should be reported privately to the owner.
- Do **not** open public issues for security vulnerabilities.
- A private channel for reporting will be established in a future sprint.

## Changes to Governance

This document may be updated by the owner at any time. Significant changes will be communicated through the repository.
